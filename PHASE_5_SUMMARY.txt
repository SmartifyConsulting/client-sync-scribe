================================================================================
                        IMPLEMENTATION PATTERN
================================================================================

All 118+ components follow this pattern:

1. IMPORT HOOK:
   import { useTranslation } from "react-i18next";

2. INITIALIZE:
   const { t } = useTranslation();

3. USE IN JSX:
   <h1>{t("components.category.component.title")}</h1>
   <button>{t("components.category.component.action")}</button>
   <p>{t("key", { count: 5 })}  // With pluralization
   <p>{t("key", { name: "John" })}  // With interpolation

4. DEFINE IN en.json:
   {
     "components": {
       "category": {
         "component": {
           "title": "Display Text",
           "action": "Action Label"
         }
       }
     }
   }

5. ADD TO OTHER LANGUAGES:
   Use English fallback for all 24 non-English language files
