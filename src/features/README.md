# Features

Domain-driven folders. Each feature owns its components, hooks, and services.

- `patients/` — patient records, profiles, connections
- `sessions/` — clinical sessions, recordings, notes, admissions
- `documents/` — invoices, prescriptions, certificates, letters, templates
- `rewards/` — lollipops, moolas, adherence
- `appointments/` — scheduling, requests, calendar
- `admin/` — admin-only pages and tools
- `insights/` — AI processing layer (placeholder)
- `uploads/` — file/storage isolation (placeholder)

Phase 1 is additive only — no existing files have been moved yet.
